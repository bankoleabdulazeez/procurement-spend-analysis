# Contributing

Thank you for your interest in improving this procurement analysis project. Please follow these guidelines when contributing:

- Reporting issues: Open issues for bugs, data problems, or questions about methodology.
- Feature requests: Use issues to propose new analyses, visualizations, or dataset extensions.
- Pull requests: Fork the repo, create a branch for your change (branch names should start with `feature/` or `fix/`), and open a PR describing the change.
- Tests & validation: When adding SQL or data transforms, include example queries and data validation steps.
- Data privacy: Do not add raw supplier pricing or PII to the public repository — use synthetic or anonymized samples in `data/`.

Maintainers will review PRs and aim to respond within a few working days.
