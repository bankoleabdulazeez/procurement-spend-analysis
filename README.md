# Project: Procurement Spend Analysis

# Objective:
Analyze procurement spending to identify major spending categories, supplier concentration, high-value items, ABC classifications, and potential cost-saving opportunities.

# Tools:

* Excel
* MySQL
* Tableau

# Key findings:

* Total procurement spend: €1.24M
* Electronics: €697.8K / 56.25% of total spend
* Electronics + Software: 83.33% of total spend
* TechMart + QuickDeliver: 49.50% of total spend
* Laptop: €472.3K / 38.07% of total spend
* A-class items: 75.64% of total spend
* 5% Electronics savings scenario: €34,890
